# Digital twin - Editor 
This is a Unity project containing editor for digital twin. <br>
The build is to be saved on the digital twin server. <br>
In this app user can create and manage:<br>
- His digital twin account
- His projects and its content
<br>
For the runtime to work you need to have the Digital twin server running.

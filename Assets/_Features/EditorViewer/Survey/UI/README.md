## Naming guide
- Kebab case for USS classes (e.g. char-data-panel, char-data-tabs, char-data-content, etc.) for UI Toolkit
- Kebab case for UXML element names (e.g. #char-data-panel, #char-data-tabs, #char-data-content, etc.) for UI Toolkit
  - exception is in QuestionSelection.uxml - names correspond with Question type files
- Pascal case for UXML files (e.g CharScreen.uxml, HomeScreen.uxml, etc.)
